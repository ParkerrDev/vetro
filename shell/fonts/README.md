The fonts the branding render outlines its lettering from
(assets/branding/render.py). The shell, the launch cards and the login screen
are set in Omarchy's own font, not these. install.sh still links this folder
to ~/.local/share/fonts/vetro.

- D-DIN, D-DIN Bold, D-DIN Exp, D-DIN Exp Bold: Datto, SIL Open Font License
  (see OFL-1.1.txt and FONTLOG.txt here).
- Nunito.ttf: Nunito (variable), The Nunito Project Authors, SIL Open Font
  License (see Nunito-OFL.txt).
- MaterialSymbolsOutlined.ttf, MaterialSymbolsRounded.ttf: Material Symbols
  (variable), Google, Apache License 2.0.
